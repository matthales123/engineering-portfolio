# Engineering Project Portfolio

FPGA, digital design, VLSI and parallel-programming projects by Matt Hales.
Each project has its own source repository and README with prerequisites, run
instructions, contribution notes and validation scope. Course projects preserve
team and instructor attribution.

- [Boids simulation](https://github.com/matthales123/u55c-boids-sim)
